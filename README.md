# Document Q&A Bot

A Python tool that answers questions about any PDF using Google's Gemini AI.

🔗 **Live demo:** (https://document-appbot.streamlit.app/)]

## How it works
1. Put a PDF file in the project folder
2. Update the filename in the script to match your PDF
3. Run the script and ask questions - answers come from the PDF's content only

## Setup
Install required libraries:
pip install google-genai pypdf python-dotenv

Add your API key to a .env file:
GEMINI_API_KEY=your-key-here

## Run
python api_test1.py
